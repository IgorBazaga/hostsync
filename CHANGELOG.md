# Changelog

All notable changes to HostSync are documented here.

## 0.1.0 - 2026-08-17

- Initial public release.
- File, SQLite and MySQL event storage.
- Server-Sent Events transport with bounded connections for shared hosting.
- Automatic JavaScript fallback to long polling.
- HMAC-signed channel tokens with read/write permissions.
- Publish rate limiting and idempotency keys.
- Countdown, scoreboard, dashboard and presentation demos.
- Zero runtime Composer dependencies.

# Code of conduct

HostSync is intended to be a practical, welcoming open-source project.

Participants are expected to discuss ideas and code respectfully, focus criticism on technical work rather than people, avoid harassment or discriminatory conduct, respect privacy, and accept maintainer decisions about project scope and moderation.

Unacceptable behavior may result in comments, issues or contributions being removed and, when necessary, participants being blocked from project spaces.

If a moderation issue involves sensitive information, contact the maintainer privately rather than opening a public issue.
